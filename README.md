Designed as a digital space for creativity and exploration, Pollar Project combines visual storytelling, interactive elements, and web technologies to create a distinctive portfolio experience.

## 🌐 Overview

Pollar Project is more than a conventional online CV. It is a personal digital playground where I experiment with web development, visual design, and interactive experiences.

The project is continuously developed as I explore new technologies, improve my technical skills, and build projects across different areas of interest.
